# 🐉 드래곤 마운틴 시티 (Dragon Mountain City)

초등학교 4~6학년을 위한 **회사 경영 & 경제·투자** 교육용 웹 게임. 회사를 도시처럼 키우고,
주식·예금·채권·ETF·금·환율을 살펴보며 **순자산(net worth) 1위**에 도전합니다.

제작: **hjpapa**

> 교육용 시뮬레이션입니다. 실제 투자 조언이 아닙니다. 등장하는 기업·인물은 실존 대상을
> 모티브로 한 가상 캐릭터이며 실제 재무 수치를 복제하지 않습니다.

## 게임 목표
**자기 회사를 잘 경영**(생산·가격·마케팅·R&D·건물 확장)해 이익을 내는 동시에,
번 돈으로 **다양한 자산에 투자**해 자본을 불립니다. 두 축이 맞물려
`현금 + 투자자산 평가액 + 기업가치 − 부채` 로 계산되는 **순자산**을 가장 크게 키우면 승리.

## 주요 기능
- 🏙️ **심시티식 회사 확장**: 격자 맵에 공장·연구소·매장·물류창고 등을 짓고 업그레이드 (움직이는 사람/차량 연출)
- 🤝 **인접 보너스**: 서로 돕는 건물을 옆에 배치하며 공간과 효율의 관계 학습
- 📈 **초등 맞춤 투자**: 주식 + 예금·채권·ETF·금·달러 환율
- 🌍 **업종·국가 선택** + **전 세계 상장기업 모티브** 또는 새 회사 생성
- 📰 **6계층 이벤트**: 거시경제 · 중앙은행 금리(연준 등) · 국가 간 · 회사 간 · 회사 내부 · 주식시장
  (인플레이션/디플레이션/스태그플레이션, AI·우주·로봇 등 최신 트렌드 반영, 악재/호재 균형, 내 선택이 확률을 바꿈)
- 👔 **인재 채용(삼국지식)**: 가상 인재를 영입·배치해 능력치 보너스
- 🧑‍💼 **CEO 비서**: 상황 요약·위험 경고·기회 알림
- 🏆 **순위 대시보드** + 🌐 **다른 회사·나라 방문**
- 🌱 **초등 전용 진행**: 시작 자금 100만 원 고정, 쉬운 말과 단계별 기능 공개
- 💾 **새로 시작 / 이어서 하기** (자동 저장)

## 기술 스택
Next.js (App Router) · React · TypeScript · Tailwind CSS · Zustand · Recharts ·
순수 TS 결정론 게임 엔진(`lib/engine`).

## 실행
```bash
npm install
npm run dev      # 개발 서버 (http://localhost:3000)
npm run build    # 프로덕션 빌드
npm test         # 게임 엔진 단위 테스트
```

## 구조
```
lib/engine/   결정론적 게임 엔진 (UI/DB 비의존, 싱글·멀티 공용)
lib/data/     업종·국가·기업 모티브·인물·스토리 카탈로그
store/        Zustand 상태 + localStorage 저장
app/          랜딩 / 설정(인트로+마법사) / 플레이 화면
components/   대시보드·맵·투자·인재·뉴스·순위·비서 등 UI
```
